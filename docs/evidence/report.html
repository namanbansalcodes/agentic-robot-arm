Long-horizon rearrangement: does an agentic loop survive horizon length and mid-episode disturbance?

Generated by python -m harness.report. Every number below is computed from episodes.jsonl; nothing on this page is hand-written.

Headline

90 episodes across 2 condition(s) and 9 scene(s). 24 of them ended in a false success — a claimed success the oracle scored as a failure.

One-shot versus agentic: what the loop bought

The two conditions share the model, the tool schema, the pixels, the scenes and the step budget. The only difference is that one plans once and executes blind while the other acts a primitive at a time and reads its own feedback. The delta is the measurement; the absolute rates are context.

Per-scene breakdown, grouped by failure mode

Every scene names the failure it was built to provoke. This is where a reader sees which failures each layer actually fixed, rather than only that the average moved.

Visual verifier error rate

L3 is the only layer that costs money, so it is the only layer that has to justify itself. Here it is marked against ground truth on disturb_h3, the scene designed to defeat it.

The disturbance only fires after the episode's first placement actually lands, so episodes that never placed a block were never disturbed; the effective sample of genuinely perturbed frames is smaller than the episode count these rates are drawn from. EpisodeResult.disturbed records which episodes it fired in.

Ground truth here is the episode outcome; the harness has no per-step oracle. That makes the false-negative rate an upper bound (an objection the agent then recovered from still counts against the verifier), while the false-positive rate has no such slack. The false-positive number is the one that matters: it is the rate at which the last layer that could have stopped a false success waved one through. It is printed above whatever it says.

The honesty gap, drawn

Longer green is better. Longer red is worse: red is the distance between what the agent said and what it did.
