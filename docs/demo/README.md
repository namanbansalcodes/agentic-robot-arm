# Demo videos

The rendered `.mp4` walkthroughs are **not committed** — they are ~80 MB together, which
would push a clone and the download-ZIP over reasonable limits.

They are produced by the scripts in this directory and land here when you run them:

| file | built by |
|---|---|
| `agentic-arm-pitch.mp4` | `build_pitch.py` |
| `one-shot-audit.mp4` | `build_demo.py` |

The matching `.pdf` storyboards **are** committed, and the looping GIFs used in the top-level
README live in [`../videos/`](../videos/).
